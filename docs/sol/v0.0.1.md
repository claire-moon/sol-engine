# SOL Engine v0.0.1

Status: development

## Objective

Create the first SOL-specific layer without modifying UZDoom's core gameplay or renderer. This release establishes the packaging, launch, validation, and design contracts required for later engine work.

## Included

- `sol/version.json`: machine-readable project and compatibility metadata.
- `sol/game/`: loadable SOL bootstrap content.
- `tools/sol-package.sh`: deterministic development PK3 packaging.
- `tools/sol-run.sh`: engine and IWAD-aware development launcher.
- `sol/maps/e1m1/PLAN.md`: vertical-slice level and encounter specification.
- `.github/workflows/sol-foundation.yml`: foundation validation.

## Explicitly deferred

- Application-wide UZDoom-to-SOL rebranding.
- Save-format changes.
- Core level-loader modifications.
- Background map streaming.
- Final E1M1 geometry or copyrighted Doom assets.
- Installer and release packaging.

## Acceptance checks

1. `bash tools/sol-package.sh` creates `build/sol/sol-v0.0.1-dev.pk3`.
2. The archive contains `ZSCRIPT`, `MAPINFO`, and the SOL bootstrap class.
3. `sol/version.json` parses as JSON.
4. `tools/sol-run.sh` reports a clear error when no engine is available.
5. With `SOL_ENGINE` set, the launcher passes the generated package to UZDoom.
6. No commercial IWAD data is added to the repository.

## Next release

`v0.1.0` begins when the editor produces a playable E1M1 graybox and the engine can run it through the shared launch contract.
