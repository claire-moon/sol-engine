# SOL Engine v0.1.0

Status: release

## Objective

Run the first E1M1 graybox with classic Doom episode progression and the exact
locked SOL presentation stack shared with `sol-editor` v0.1.0.

## Included

- E1M1 MAPINFO identity and normal progression to E1M2/E1M9.
- Episode 1 cluster, title patch, secret target, par time, and classic intermission.
- Correct root ZScript `#include` directive and packaged regression check.
- Wadpack contract 2 with eighteen fixed third-party resources.
- Bundle contract 1 with canonical final runtime name `sol.pk3`.
- Eighteen intact third-party archives plus SOL runtime and E1M1 content.
- Numbered root-level `.wad` carrier names using UZDoom's native embedded-resource loader.
- One-file runtime launch through `-file sol.pk3`.
- `SOLPACK.json` hashes and embedded `THIRD_PARTY.md` attribution/provenance.
- Self-contained packaged `sol-engine` launcher placed beside UZDoom and `sol.pk3`.
- Shared SOL branding.

Wadpack contract 2 keeps the original fourteen resources in positions 1–14 and
appends Universal Ambience, CosmoAmbience Script edited, Ambient decorations,
and TargetSpy v3.1.0 in positions 15–18.

## Package model

`tools/sol-runtime-package.sh` creates the SOL-owned engine component
`sol-v0.1.0.pk3`. The complete local product package is `sol.pk3`, assembled by
the sibling editor bundler and copied into engine/editor build outputs.

The final order inside the bundle is:

```text
01–18  third-party resources
19     SOL runtime component
20     SOL E1M1 content component
```

Each archive is stored intact under a numbered root-level `.wad` carrier name.
The suffix activates UZDoom's existing embedded-resource handling; UZDoom then
opens each carrier by actual file content. No child archive is converted to WAD
format and no gameplay extraction step is required.

The packaged `sol-engine` launcher loads adjacent `sol.pk3` automatically. With
`DOOM_IWAD` set it uses that IWAD; otherwise UZDoom's normal discovery/picker is
left intact.

## Release checks

1. The SOL-owned runtime component contains valid MAPINFO and the canonical ZScript include.
2. `tools/sol-run.sh` uses the self-contained SOL launcher and does not require the editor checkout at runtime.
3. The packaged launcher supplies exactly one `-file sol.pk3` resource argument.
4. Engine CI asserts UZDoom's root `.wad` embedded-resource detection and recursive resource addition remain present.
5. Metadata identifies editor contract `0.1.0`, wadpack contract 2, eighteen resources, and bundle contract 1.
6. Bundle tooling preserves the exact ordered child archive bytes instead of flattening conflicting mod namespaces.
7. `SOLPACK.json` records and verifies every embedded component SHA-256.
8. `THIRD_PARTY.md` is committed and embedded in the complete bundle.
9. E1M1 remains “Hangar: Arrival” with normal E1M2/E1M9 progression and no `nointermission` override.
10. Existing UZDoom build workflows and SOL validation remain the source merge gate.

## Distribution boundary

The complete `sol.pk3` is currently a local-build development/test artifact.
Attribution and preserved notices do not themselves grant redistribution rights.
Several resources still require asset/license review, while HQ PlayStation music
and sound effects remain local-only proprietary audio. Public binary release of
the full bundle remains blocked until that audit is complete.
