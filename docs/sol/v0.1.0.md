# SOL Engine v0.1.0

Status: release

## Objective

Run the first complete E1M1 graybox produced by `sol-editor` while keeping core UZDoom behavior and classic Doom episode progression intact, and make the approved SOL visual/gameplay stack mandatory and deterministic.

## Included

- Engine/editor compatibility metadata for `0.1.0`.
- E1M1 MAPINFO identity and normal progression to E1M2.
- Explicit Episode 1 cluster, level number, title patch, secret-exit target, and par time.
- Classic level-complete statistics and Episode 1 "you are here" intermission map.
- Fixed eight-file mod manifest and strict local resolver.
- Deterministic launch order: fixed mods, SOL runtime package, then authored SOL content.
- Local SOL-engine-only launcher; no fallback to a generic system UZDoom executable.
- Updated runtime bootstrap message and shared SOL application icon.
- Validation for package contents, metadata, branding, intermission fields, required mod presence, and runtime argument order.

## Fixed mod stack

The canonical order is defined by `sol/mods/stack.txt` and documented in `docs/sol/mod-stack.md`. The archives remain local vendor inputs until redistribution rights and provenance are verified.

## Acceptance checks

1. `tools/sol-package.sh` produces `sol-v0.1.0.pk3`.
2. The PK3 contains MAPINFO, ZSCRIPT, and the SOL bootstrap class.
3. `tools/sol-mod-stack.sh --check` rejects incomplete stacks and accepts the exact eight-file stack.
4. `tools/sol-run.sh` loads the eight fixed mods in manifest order before the SOL runtime package.
5. The editor graybox package can be loaded after the runtime package.
6. E1M1 starts as “Hangar: Arrival” and exits normally toward E1M2.
7. The Doom statistics screen and Episode 1 world map appear after completion.
8. MAPINFO does not use `nointermission` or seamless-transition behavior.
9. Existing UZDoom compilation workflows remain green.
10. A local run records no ZScript or MAPINFO errors.
