# SOL Engine v0.1.0

Status: release

## Objective

Run the first E1M1 graybox with classic Doom episode progression and the exact
locked SOL visual/audio resource stack shared with `sol-editor` v0.1.0.

## Included

- E1M1 MAPINFO identity and normal progression to E1M2/E1M9.
- Episode 1 cluster, title patch, secret target, par time, and classic intermission.
- Correct root ZScript `#include` directive and packaged regression check.
- Wadpack contract 2 with eighteen fixed third-party resources.
- Bundle contract 1 with canonical final runtime name `sol.pk3`.
- Eighteen intact embedded WAD/PK3 components plus SOL runtime and E1M1 content.
- `SOLPACK.json` hashes and embedded `THIRD_PARTY.md` attribution.
- Engine/editor launcher convergence on the same bundle and component order.
- Shared SOL branding.

Wadpack contract 2 keeps the original fourteen resources in positions 1–14 and
appends Universal Ambience, CosmoAmbience Script edited, Ambient decorations,
and TargetSpy v3.1.0 in positions 15–18.

## Package model

`tools/sol-runtime-package.sh` creates the SOL-owned engine component
`sol-v0.1.0.pk3`. The complete local product package is `sol.pk3`, assembled by
the sibling editor bundler and copied into engine/editor build outputs.

The final order inside the bundle contract is:

```text
01–18  third-party resources
19     SOL runtime component
20     SOL E1M1 content component
```

Runtime wrappers verify and materialize the child archives from `sol.pk3`; they
do not require eighteen loose runtime files after the bundle has been built.

## Release checks

1. The SOL-owned runtime component contains valid MAPINFO and the canonical ZScript include.
2. `tools/sol-run.sh` resolves the sibling SOL launcher and does not fall back to generic system UZDoom.
3. Metadata identifies editor contract `0.1.0`, wadpack contract 2, eighteen resources, and bundle contract 1.
4. Bundle tooling preserves the exact ordered child archives instead of flattening conflicting mod namespaces.
5. `SOLPACK.json` records and verifies every embedded component SHA-256.
6. `THIRD_PARTY.md` is committed and embedded in the complete bundle.
7. E1M1 remains “Hangar: Arrival” with normal E1M2/E1M9 progression and no `nointermission` override.
8. Existing UZDoom build workflows and SOL validation remain the source merge gate.

## Distribution boundary

The complete `sol.pk3` is currently a local-build development/test artifact.
Attribution and preserved notices do not themselves grant redistribution rights.
Several resources still require license review, while HQ PlayStation music and
sound effects remain recorded as local-only proprietary audio. Public binary
release of the full bundle remains blocked until that audit is complete.
