# SOL Engine v0.1.0

Status: development

## Objective

Run the first E1M1 graybox with classic Doom episode progression and the exact
locked SOL visual/audio resource stack.

## Included

- E1M1 MAPINFO identity and normal progression to E1M2.
- Episode 1 cluster, title patch, secret target, par time, and classic intermission.
- Shared Midnight Commander setup entry point.
- Correct root ZScript `#include` directive and packaged regression check.
- Engine launcher delegation to the sibling editor's locked wadpack contract.
- Automatic current runtime and map package loading.
- Shared SOL branding.

## Acceptance checks

1. The runtime PK3 contains valid MAPINFO and ZScript.
2. `tools/sol-run.sh` resolves the sibling `sol-test.sh` launcher.
3. All fourteen locked wadpack files load before SOL runtime and map content.
4. Missing or changed wadpack resources block launch.
5. The configured engine executable resolves inside this checkout.
6. E1M1 starts as “Hangar: Arrival” and exits normally toward E1M2.
7. The statistics screen and Episode 1 world map appear after completion.
8. Existing UZDoom compilation workflows remain green.
9. A local run records no ZScript, MAPINFO, or resource errors.
