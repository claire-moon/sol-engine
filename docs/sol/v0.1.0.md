# SOL Engine v0.1.0

Status: development

## Objective

Run the first complete E1M1 graybox produced by `sol-editor` while keeping core UZDoom behavior and classic Doom episode progression intact.

## Included

- Engine/editor compatibility metadata for `0.1.0-dev`.
- E1M1 MAPINFO identity and normal progression to E1M2.
- Explicit Episode 1 cluster, level number, title patch, secret-exit target, and par time.
- Classic level-complete statistics and Episode 1 "you are here" intermission map.
- Updated runtime bootstrap message.
- Shared SOL icon integrated into engine application branding.
- Validation for package contents, metadata, icon files, and intermission-preserving MAPINFO fields.

## Acceptance checks

1. `tools/sol-package.sh` produces the runtime PK3.
2. The PK3 contains MAPINFO, ZSCRIPT, and the SOL bootstrap class.
3. The editor graybox package can be loaded beside the runtime package.
4. E1M1 starts as “Hangar: Arrival” and exits normally toward E1M2.
5. The Doom statistics screen and Episode 1 world map appear after completion.
6. MAPINFO does not use `nointermission` or any seamless-transition behavior.
7. Existing UZDoom compilation workflows remain green.
8. A local run records no ZScript or MAPINFO errors.
