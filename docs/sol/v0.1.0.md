# SOL Engine v0.1.0

Status: development

## Objective

Run the first complete E1M1 graybox produced by `sol-editor` while keeping core UZDoom behavior unchanged.

## Included

- Engine/editor compatibility metadata for `0.1.0-dev`.
- E1M1 MAPINFO identity and progression contract.
- Updated runtime bootstrap message.
- Shared SOL icon integrated into engine application branding.
- Validation for package contents, metadata, and icon files.

## Acceptance checks

1. `tools/sol-package.sh` produces the runtime PK3.
2. The PK3 contains MAPINFO, ZSCRIPT, and the SOL bootstrap class.
3. The editor graybox package can be loaded beside the runtime package.
4. E1M1 starts as “Hangar: Arrival” and exits toward E1M2.
5. Existing UZDoom compilation workflows remain green.
6. A local run records no ZScript or MAPINFO errors.
