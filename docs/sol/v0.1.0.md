# SOL Engine v0.1.0

Status: release

## Objective

Run the first E1M1 graybox with classic Doom episode progression and the exact
locked SOL visual/audio resource stack shared with `sol-editor` v0.1.0.

## Included

- E1M1 MAPINFO identity and normal progression to E1M2.
- Episode 1 cluster, title patch, secret target, par time, and classic intermission.
- Shared Midnight Commander setup entry point.
- Correct root ZScript `#include` directive and packaged regression check.
- Engine launcher delegation to the sibling editor's eighteen-resource wadpack contract.
- Automatic current runtime and map package loading.
- Shared SOL branding.
- Final `0.1.0` runtime package identity: `sol-v0.1.0.pk3`.

Wadpack contract 2 keeps the original fourteen resources in positions 1–14 and
appends Universal Ambience, CosmoAmbience Script edited, Ambient decorations,
and TargetSpy v3.1.0 in positions 15–18.

## Release checks

1. The runtime PK3 contains valid MAPINFO and the canonical ZScript include.
2. `tools/sol-run.sh` resolves the sibling `sol-test.sh` launcher and does not fall back to a generic system UZDoom installation.
3. The shared launch contract requires eighteen locked wadpack resources before SOL runtime and map content.
4. Missing or changed wadpack resources block launch in the sibling editor tooling.
5. Release metadata identifies editor contract `0.1.0`, wadpack contract 2, and eighteen resources.
6. E1M1 is configured as “Hangar: Arrival” with normal E1M2/E1M9 progression and no `nointermission` override.
7. The runtime package is reproducibly generated as `sol-v0.1.0.pk3`.
8. Existing UZDoom build workflows and the SOL validation workflow remain the release merge gate.

## Local deployment requirement

The third-party wadpack is not redistributed by this repository. Runtime launch
is intentionally delegated to the sibling editor's verified local wadpack. A
complete machine-level gameplay pass requires all eighteen resources, including
the locally supplied HQ PSX music archive, and remains a post-installation
verification step rather than a substitute for source-level CI.
